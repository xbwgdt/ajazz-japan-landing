# 亚马逊优先与颜色独立图集设计

## 已确认目标

用户确认：官网商品在AJAZZ自己的亚马逊日本店中存在对应型号及颜色时，优先使用该亚马逊商品图片。选择颜色后，主图与整组缩略图一起切换，不混入其他颜色的图片。图片保存到官网现有R2图库，后台可以维护。

首期仅实现功能并整理AF84六色测试站草稿；其他商品待样例验收后分批迁移。本期不发布商品，不修改价格、库存、SKU、JAN、分类、商品规格或名称，不修改亚马逊、楽天或Yahoo店铺。

## 现状与影响范围

- `cms/fields/productVariants.ts`：变体只有 `thumbnailId` 和 `imageId`，没有颜色专属图集。
- `components/store/ProductDetail.tsx`：当前画廊将选中颜色的主图与商品级全部图片合并，所以切色不切换整组图片。
- 草稿预览由 `app/products/[slug]/preview-adapter.ts` 转换CMS数据。
- 正式发布经 `lib/cms/publication-route.ts`、`publication.ts`、`publication-store.ts` 写入运营数据库，正式详情由 `lib/commerce/storefront-db.ts` 读取。
- 媒体引用校验、归档与删除保护也必须识别新增的颜色图集，不能只改前台组件。

## 数据设计

1. 商品增加图集模式：原有共享模式、颜色独立模式。既有商品默认保持原有模式，避免未经审核的全站变更。AF84完成六色审核后，整个商品切换为颜色独立模式。
2. 每个变体增加有序的 `galleryImageIds` 媒体关系，后台可追加、移除、排序。保留现有主图和缩略图字段，主图作为画廊第一张，重复图片按媒体ID或最终URL去重。
3. 每个变体记录来源商品网址和ASIN，记录在可编辑的图片来源字段中，不覆盖RMS `sourceSnapshot` 或库存关联标识。来源字段不自动触发远端抓取，也不向顾客展示。
4. 草稿、版本历史和已发布运营数据均保存模式及有序颜色图集。运营数据库使用独立变体图片关联表记录变体、媒体ID、URL和顺序，并在现有发布事务中替换目标变体图集。
5. 所有新媒体必须通过现有媒体上传和验证流程，前台使用官网媒体地址，不把亚马逊图片URL直接用作长期展示地址。

## 前台行为

- 颜色独立模式：画廊仅使用该颜色主图和该颜色图集，不自动追加商品级混合图片。
- 切换颜色时，选中状态、主图、缩略图、SKU及价格保持同一变体，并将画廊位置重置为第一张。
- 某颜色只有主图时，只展示主图；不补入其他颜色图片。缺少全部有效图片时显示现有空图状态，不虚构图片。
- 本期不新增自动共享图片规则。确实适用于多个颜色的素材，也须人工确认后分别关联，不能凭文件名自动判定。
- 缺货颜色仍可浏览；预览显示「プレビュー・購入不可」并禁止购买。购买资格继续由现有实际库存和销售规则决定。
- 原有共享模式商品保持兼容，直到该商品完成来源核对并启用颜色独立模式。不会宣称尚未迁移的商品已经实现全套颜色图。

## 亚马逊来源核对

- 从用户提供的AF84绿色ASIN `B0H4LT2P97` 页面沿实际颜色选项查找各颜色对应页面，不猜测ASIN、不按相似名称合并型号。
- 每条映射至少记录：官网变体SKU、颜色名、亚马逊ASIN、商品页面、图片顺序及图片网址。仅在型号和颜色确认一致后导入。
- 已确认绿色SKU为 `6976412988448`，其亚马逊主图来源为 `https://m.media-amazon.com/images/I/71dYWnWQ6jL._AC_SL1500_.jpg`。其余颜色的ASIN和整组图片尚需逐一读取，不以本设计文档视为已核实。
- 不复制亚马逊推荐商品、广告、用户评论照片或与所选颜色不一致的图；不导入平台排名海报。
- 图片无法访问、商品跳转到另一型号、没有准确颜色映射或来源图片本身混色时，标记异常并保留旧数据，不静默替换。
- 亚马逊无对应商品时保留原有已审核图片。原有其他颜色图片不能当作当前颜色的补图。
- 本期不建立自动亚马逊同步，不依赖自动抓取保证全店完整性；分批迁移均提供完成、跳过和待核实清单。

## 数据安全与部署

- 数据库结构变更采用增量迁移，覆盖CMS主记录、版本历史及运营表；先在隔离测试数据库验证，不启用运行时自动结构推送。
- 迁移与功能发布不自动发布任何商品草稿。首批只部署Railway staging，生产环境不动。
- AF84替换前保存全部图集与变体关联及必要比较字段的快照，形成可追溯的前后对应表；旧媒体保留，不删除。
- 图集替换使用已有编辑版本并发检查，遇到他人保存立即停止并重新核对；不覆盖用户同时进行的修改。
- 新增颜色图集纳入退休媒体拒绝、引用保护、归档引用识别和发布前媒体校验。
- 发布时写入同一事务：若图集校验或写入失败，整体回滚，不能产生主图已更新但图集未更新的半完成发布。
- 恢复优先回退商品图集模式和关联，保留增量表结构；不通过删除新表来回滚，避免丢失已编辑的图集。

## 验收标准

1. 后台每个颜色可保存多图并调整顺序；保存、重新打开、版本读取后顺序一致。
2. AF84六色分别完成型号与颜色来源核对；无法获得某色整组图时明确列出，不使用其他颜色代替。
3. 草稿预览切换六色时，全部缩略图与主图属于该颜色，SKU正确，默认显示第一张；图库较长切换到较短时不出现空图。
4. 正式发布链路通过测试数据验证颜色图集保存、读取、顺序、去重、回滚及无效媒体拒绝；不为验证而发布真实AF84商品。
5. 新增媒体关系受到引用保护；已被使用的颜色图不会被误清理。
6. 预览不能购买，真实零库存不能购买；有库存商品既有购物车行为不退化。
7. 桌面和390px手机页面无横向溢出，图片加载无错误，可用键盘选择颜色，ARIA选中状态准确。
8. AF84前后对照确认价格、库存、SKU、JAN、规格、名称、分类和发布状态不变；其他商品未变。

6. 仅更新AF84测试站草稿，完成桌面/手机版本验收及前后数据对照，交用户检查后再安排其他商品。
